How it works

A sidecar for Claude Desktop. No subscription, no middleman — your key goes only to the provider you choose.

1

Download & open

Unzip and open Keyway. Paste your endpoint, API key, and model.

2

Keyway connects

It starts a loopback gateway, writes Claude Desktop's profile, and restarts it.

3

Claude uses your models

Pick a model in Claude Desktop. The menu bar shows ✓ Connected.

Claude Desktop ──▶  127.0.0.1:8788 (Keyway)  ──▶  your provider

Works with what you already have

Keyway auto-detects the endpoint's protocol — Anthropic pass-through, or OpenAI ↔ Anthropic translation (streaming and tool calls included).

Anthropic-compatible

Anthropic, DeepSeek (anthropic), or any /v1/messages endpoint. Used directly.

OpenAI-compatible

OpenAI, OpenRouter, Groq, Together, vLLM, llama.cpp, Ollama… translated automatically.

Features

Install

Users

1. Download Keyway-Setup.zip and unzip.
2. Right-click Keyway.app → Open (once, to pass Gatekeeper).
3. Enter provider, API key, model(s) → Install.
4. Claude Desktop restarts on your models.

From source

git clone https://github.com/shivamtiwari3/keyway
cd keyway

FAQ

Is my API key safe?

Yes. Keyway binds to 127.0.0.1 only and stores your key at ~/Library/Application Support/Keyway/key (mode 600). It is sent only to the endpoint you configure. No telemetry.

Do I need Node, Xcode, or a terminal?

No. The release app bundles its own runtime. Right-click → Open, paste your key, done.

Which providers work?

Anything OpenAI- or Anthropic-compatible — OpenAI, Anthropic, OpenRouter, Groq, DeepSeek, Together, or a local Ollama/llama.cpp/vLLM server.

Why does it ask to restart Claude Desktop?

Claude Desktop reads its provider profile only at startup, so Keyway writes it and restarts the app.

How do I uninstall?

Open Keyway again → Remove. It stops the gateway, removes the profile, and restores Claude Desktop.

Is it free?

Yes — MIT licensed. You only pay your model provider.
